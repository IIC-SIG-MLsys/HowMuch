# AI 部署成本计算器（HowMuch）

一个纯静态、可直接部署到 GitHub Pages 的网页版 AI 部署成本/收益计算器。它帮助你在询价之后，快速估算租用或购买 GPU 集群部署生产级大模型（默认聚焦 DeepSeek-V4-Flash / V4-Pro）的吞吐上限、月度成本、收入和盈利空间。

> 项目名称取 “How much does it cost / how much can I earn” 之意。

## 功能

- **模型预设**：DeepSeek-V4-Flash（284B/13B 激活）、V4-Pro（1.6T/49B 激活），支持自定义模型与量化位数
- **硬件预设**：H100 / H200 / B300，支持自定义带宽、算力、显存、时租与采购价
- **优化策略**：DSpark 推测解码（默认 1.6×）、Mooncake/LMCache 式 KV 缓存池（命中率、分层卸载容量）、PD 分离（可选 +15%）
- **四种商业模式**：官方价转售/自用替代、溢价转售、私有化合同、混合策略
- **结果输出**：单机解码/预填充吞吐、每小时 token 产能、所需并发、KV 容量上限、月度收入/成本/毛利、盈亏平衡负载率与输出价、采购回本周期
- **敏感性分析**：负载率 × 输出价热力图、关键参数 ±20% Tornado 图、负载率-利润曲线
- **换卡对比**：同一套参数下 H100 / H200 / B300 的收益对比表
- **租买对比**：按折旧周期对比租用与采购的总成本
- **可保存配置**：本地自动持久化，支持 JSON 导出/导入
- **分享与打印**：一键生成带完整参数的可分享链接；打印/PDF 报告
- **中英双语金额**：USD / CNY 一键切换

## 快速开始

本项目无构建步骤、无后端依赖，图表库已内置于 `vendor/echarts.min.js`。

```bash
# 方式一：直接双击打开 index.html

# 方式二：本地静态服务器
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 把本仓库推送到 GitHub（仓库名任意，例如 `HowMuch`）。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。
5. 等待 1–2 分钟，页面会出现在 `https://<用户名>.github.io/<仓库名>/`。

所有资源均为相对路径，无需修改任何配置。

### 组织已有主页时（子页面部署）

如果组织名下已经有主页（仓库名为 `<组织名>.github.io`，占用 `https://<组织名>.github.io/`），这个项目会作为**项目页面（project site）**部署，二者互不冲突：

```text
https://<组织名>.github.io/          ← 已有主页（<组织名>.github.io 仓库）
https://<组织名>.github.io/HowMuch/  ← 本项目（HowMuch 仓库）
```

- 子页面 URL 由**仓库名**决定：仓库叫 `HowMuch`，URL 就是 `/HowMuch/`；改名会同步改变 URL。
- 本项目全部使用相对路径（`css/`、`js/`、`vendor/`），天然支持子路径部署，不需要额外改代码。
- 如果组织主页配置了自定义域名，项目页面默认继承同一域名：`https://<你的域名>/HowMuch/`。
- 如果想让项目出现在主页仓库的某个子目录（如 `<主页仓库>/calculator/`），也可以把构建产物直接放进主页仓库，但不推荐，维护更麻烦。

## 使用建议

1. 先点顶部**快捷场景**（官方价转售 / 溢价转售 / 私有化 / 混合），建立基准。
2. 询价后，把真实租金、折扣、采购价、电价填入“参数设置”中的橙色字段。
3. 建议用真实业务流量回放压测，把**带宽利用率**（默认 45%）、**缓存命中率**（默认 70%）、**DSpark 倍率**（默认 1.6×）修正为实测值。
4. 看“收益测算”页的**盈亏平衡负载率**、**租买对比**与“敏感性分析”页的热力图，判断风险边界。
5. 需要把当前方案发给别人时，点“分享链接”复制带参数的 URL；打开即可恢复同样的配置。

## 计算模型（摘要）

```text
权重占用        = 总参数量 × 字节/参数 × (1 + 运行时开销%)
单卡解码吞吐    = 显存带宽 ÷ (激活权重字节 + KV 读取字节) × 带宽利用率 × DSpark 倍率
单节点预填充    = FP8 算力 ÷ (2 × 激活参数量) × GPU 数 × 预填充效率
输出 token/时   = 解码吞吐 × 3600 × 负载率 × API 节点数
输入 token/时   = 输出 × 输入输出比（受预填充上限约束）
API 收入        = 输出 × 输出价 + 输入 × (命中率 × 缓存价 + (1−命中率) × 输入价)
月度成本        = 租金(或折旧+维护) + 电费 + 机房运维
盈亏平衡负载率  = (固定成本 − 私有化固定收入) ÷ (单位负载率收入 − 单位负载率电费)
```

详细公式与假设见 [docs/methodology.md](docs/methodology.md)。

## 局限性

- 解码按**显存带宽受限**建模，未建模注意力 O(n²)、跨卡通信、调度与排队延迟；长上下文、高并发下实际吞吐通常低于模型估算。
- 吞吐、命中率、价格均为**估算值**，请以实测压测和签约报价为准。
- DeepSeek 官方 API 已于 2026-08-16 切换为峰谷分时计价，本工具内置了该口径（高峰 = 非高峰 × 2）。
