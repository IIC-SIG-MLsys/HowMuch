计算模型

权重占用 = 总参数量 × 字节/参数 × (1 + 运行时开销%)

单卡解码吞吐 = 显存带宽 ÷ (激活权重字节 + KV 读取字节) × 带宽利用率 × DSpark 倍率

单节点预填充吞吐 = FP8 算力 ÷ (2 × 激活参数量) × GPU 数 × 预填充效率

输出 token/时 = 解码吞吐 × 3600 × 负载率 × API 节点数

输入 token/时 = 输出 × 输入输出比（受预填充能力上限约束）

API 收入 = 输出×输出价 + 输入×(命中率×缓存价 + (1−命中率)×输入价)

月度成本 = 租金(或折旧+维护) + 电费 + 机房运维；电费随负载率线性变化

盈亏平衡负载率 = (固定成本 − 私有化固定收入) ÷ (每单位负载率收入 − 每单位负载率电费)

关键简化：解码按带宽受限建模，未建模注意力 O(n²) 计算、跨卡通信、调度损耗与排队延迟；实际生产值请以压测为准。
